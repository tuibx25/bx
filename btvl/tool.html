🔧 Tool chuyển đổi đề thi → HTML

Chuyển file đề (c.html) + file đáp án (d.html) thành HTML để paste vào hệ thống trắc nghiệm

📋 Hướng dẫn sử dụng:
  1. Dán nội dung file đề (c.html) vào ô bên trái
  2. Dán nội dung file đáp án (d.html) vào ô bên phải
  3. Bấm "🔄 Chuyển đổi"
  4. Kiểm tra kết quả ở tab Preview
  5. Bấm "📋 Copy HTML" → dán vào form thêm đề trên index
